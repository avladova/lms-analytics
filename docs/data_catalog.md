# Каталог корректированных LMS-выгрузок

## Назначение

Этот каталог фиксирует минимальную, проверяемую информацию о корректированном корпусе в `data/`. Он не заменяет детальный словарь учебных активностей и не публикует индивидуальные результаты. Его цель — сделать выбор данных, периодов и ограничений явным до начала статистического анализа или машинного обучения.

## Результаты структурного профилирования

Профилирование в режиме `read_only` охватило все файлы `*_correct.xlsx` на ветке `main` по состоянию на 21 августа 2026 года. Ошибок чтения не обнаружено.

| Показатель | Значение | Комментарий |
| --- | ---: | --- |
| Корректированные XLSX-книги | 26 | Минимальный корпус для сравнительных расчётов |
| Рабочие листы | 26 | В каждой книге обнаружен один используемый лист |
| Строки, включая заголовки | 46 747 | Не равно числу уникальных студентов |
| Строк на лист | 223–3 366 | Размер когорт и выгрузок различается |
| Столбцов на лист | 20–185 | Состав учебных активностей неоднороден |
| Названия листов | `Оценки`, `Лист1` | Нельзя использовать имя листа как дисциплинарный ключ |
| Первая непустая строка | 1 | Заголовки расположены в первой строке |

Часто встречаются поля `Участник групп`, `хеш` и `Итоговая оценка за курс (Значение)`, но их наличие и точное написание следует проверять для каждого файла программно. Имена дисциплин, типов работ и тем должны выводиться из утверждённого словаря, а не из имени файла по неформальному правилу.

## Нерешённые вопросы данных

| Вопрос | Риск при игнорировании | Нужный артефакт |
| --- | --- | --- |
| Какому курсу и периоду соответствует файл? | Некорректное межгодовое сравнение | Манифест источников |

## Воспроизводимое профилирование

Команда ниже формирует JSON, CSV и Markdown-описание структуры XLSX-файлов, не меняя источник:

```bash
python scripts/profile_lms_workbooks.py \
  --input-dir data \
  --pattern '*_correct.xlsx' \
  --output-dir artifacts/data_profile
```

Перед обучением модели или построением графика сохраните ссылку на выпуск данных, имя файла, хеш, версию словаря и правило преобразования. Это минимальный уровень трассируемости для научного результата.
