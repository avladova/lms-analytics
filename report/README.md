# Отчёты и научные материалы

Каталог `report/` содержит статьи, формализованные постановки и агрегированные результаты. Исходные индивидуальные выгрузки, списки студентов группы риска, ключи сопоставления и неагрегированные предсказания не должны попадать в контроль версий.

| Подкаталог / вид | Допустимое содержимое | Проверка перед публикацией |
| --- | --- | --- |
| `data_profile/` | Структура файлов, поля, доли пропусков | Нет значений отдельных студентов и малых групп |
| `figures/` | Агрегированные графики | Проверены подписи, шкалы, период и риск идентификации |
| `model_cards/` | Назначение модели, данные, валидация, метрики, ограничения | Нет индивидуальных результатов; указан допустимый сценарий использования |
| `interventions/` | Итоги пилотов поддержки | Описаны критерии эффекта, период и этические ограничения |

Минимальный отчёт должен содержать вопрос, период, единицу наблюдения, версию источников и словаря, правила пропусков/попыток, схему валидации, выводы и ограничения. При добавлении материала с внешним происхождением необходимо проверить права на публикацию и корректность цитирования.
