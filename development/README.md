# Разработка и аналитические эксперименты

Каталог содержит код импорта, преобразования данных, статистической проверки и прототипирования аналитических сервисов. Исторические R-скрипты в `R/` сохранены как примеры, однако абсолютные пути к рабочему столу не допускаются в новых экспериментах.

## Требования к новому коду

| Принцип | Требование |
| --- | --- |
| Пути | Путь к входному файлу передаётся параметром или строится от корня репозитория; не используется `setwd()` и путь рабочего стола. |
| Источник | Скрипт принимает только явно указанный файл/список файлов и записывает их имена, хеши и период в результат. |
| Преобразования | Любое сопоставление заголовков выполняется через версионируемый словарь, а не через незафиксированные ручные замены. |
| Результаты | Выходы сохраняются в `report/` только в агрегированном и безопасном виде. |
| Моделирование | Признаки доступны на дату среза; схема временной валидации описана рядом с кодом. |
| Документация | Для сценария указаны цель, входы, выходы, запуск и ограничения. |

## Рекомендуемая структура нового эксперимента

```text
development/
  R/ or python/
    01_profile_sources.*
    02_normalise_activities.*
    03_build_long_dataset.*
    04_descriptive_metrics.*
    05_temporal_baseline.*
```

Каждый этап создаёт понятный промежуточный артефакт и не перезаписывает исходные XLSX-файлы. До добавления новой модели необходимо реализовать базовую версию и зафиксировать, какое педагогическое действие может последовать за её сигналом.
