# Данные LMS

Каталог содержит исходные и корректированные XLSX-выгрузки результатов обучения по дисциплинам математического цикла за 2022/23–2024/25 учебные годы. Исходные файлы сохранены как свидетельство происхождения; для воспроизводимых сравнительных расчётов приоритет имеют файлы с суффиксом **`_correct.xlsx`**.

## Состав корректированного корпуса

Структурное профилирование в режиме чтения обнаружило 26 корректированных рабочих книг и 26 листов без ошибок чтения. На листах содержится суммарно 46 747 строк вместе с заголовками; размер файлов неоднороден — от 223 до 3 366 строк и от 20 до 185 столбцов. Встречаются листы `Оценки` и `Лист1`; первая непустая строка у всех профилированных листов — строка 1.

| Группа файлов | Учебные годы | Пример | Комментарий |
| --- | --- | --- | --- |
| `AD_*_correct.xlsx` | 2022/23–2024/25 | `AD_1(24-25)_correct.xlsx` | Анализ данных; названия и состав заданий меняются между годами |
| `CP*_correct.xlsx` | 2022/23–2024/25 | `CP_2_24-25_correct.xlsx` | Компьютерный практикум; требуется словарь работ |
| `DM*_correct.xlsx` | 2022/23–2024/25 | `DM_RE_(24-25)_correct.xlsx` | Цифровая математика / связанные курсы |
| `English_DA_*_correct.xlsx` | 2022/23–2024/25 | `English_DA_2(24-25)_correct.xlsx` | Англоязычные потоки анализа данных |
| `MAT_*_correct.xlsx` | 2022/23–2024/25 | `MAT_1(24-25)_correct.xlsx` | Математика; состав тестов различается по годам |
| `M_*_correct.xlsx` | 2023/24–2024/25 | `M_2_24-25_RE_correct.xlsx` | Дополнительные математические дисциплины |

## Поля и единица наблюдения

В большинстве файлов присутствуют псевдонимизированный столбец `хеш`, поле `Участник групп` и поле итоговой оценки. Они не образуют полностью готовую аналитическую таблицу: одна строка обычно соответствует студенту в выгрузке, а учебные активности представлены широким набором столбцов. Для анализа разных периодов данные необходимо преобразовать в длинную структуру «студент–группа–дисциплина–задание–период».

| Поле целевой структуры | Назначение |
| --- | --- |
| `student_hash` | Псевдонимный идентификатор; запрещён к публикации вместе с квазиидентификаторами |
| `group_id`, `course_id`, `term` | Учебный и временной контекст |
| `activity_raw_name` | Исходное название столбца для аудита |
| `activity_code`, `activity_type`, `topic_code` | Нормализованный результат применения словаря |
| `score`, `score_max`, `attempt_rule` | Результат и правило выбора попытки |
| `assigned_flag`, `completion_status` | Различение назначения, невыполнения, нуля и отсутствия данных |
| `source_file`, `source_sha`, `dictionary_version` | Происхождение и воспроизводимость |

## Обязательные правила использования

| Риск | Требуемое действие |
| --- | --- |
| Вариативные названия работ | Применить версионируемый словарь, не объединять заголовки вручную без журнала сопоставлений |
| Пропуски и прочерки | Не заменять автоматически нулём; хранить статус наблюдения |
| Повторные попытки / пересдачи | До анализа утвердить правило агрегации попыток и записать его в отчёте |
| Разные максимальные баллы | Нормировать внутри активности и документировать шкалу |
| Малые группы | Не публиковать индивидуальные или потенциально идентифицируемые результаты |

Для повторного аудита используйте `scripts/profile_lms_workbooks.py`. Скрипт не изменяет XLSX-файлы и сохраняет CSV, JSON и Markdown-профиль в указанный каталог результатов.
